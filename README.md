# cirrus-cloudflare-agent

> A full-stack AI agent built entirely on Cloudflare — no traditional hosting, just a domain.

🌐 **Live demo**: [focuseffect.fr](https://focuseffect.fr)

---

## What is this?

**Cirrus** is an AI-powered web agent that runs 100% on Cloudflare's edge infrastructure. No servers. No traditional hosting. No cloud VMs. Just a domain name and Cloudflare.

It demonstrates that you can build a complete, production-grade application — with persistent memory, real-time AI responses, live data feeds, and a dynamic frontend — using only Cloudflare products.

---

## Cloudflare Stack

| Product | Role | Details |
|---|---|---|
| **Cloudflare Pages** | Frontend hosting | Static site deployed at the edge, globally distributed |
| **Cloudflare Workers** | Backend / API | Handles all AI requests, routing, and logic |
| **Workers AI** | LLM inference | `@cf/meta/llama-3.3-70b-instruct-fp8-fast`, max_tokens: 2048 |
| **AI Gateway** | Caching + monitoring | TTL 3600s, request logging, cost visibility |
| **Workers KV** | Persistent memory | Stores last 3 conversation turns per user, TTL 7 days |
| **Cloudflare DNS** | Custom domain | `focuseffect.fr` → CNAME → Pages deployment |

## Architecture

```
User Browser
    │
    ▼
focuseffect.fr  (Cloudflare DNS)
    │
    ▼
Cloudflare Pages  (frontend — HTML/CSS/JS, edge-served)
    │
    ▼
Cloudflare Worker  (backend — POST /chat, GET /news)
    ├── Workers AI  →  LLM response (Llama 3.3 70B)
    ├── AI Gateway  →  Cache + monitoring layer
    └── Workers KV  →  Conversation memory (per userId)
```

Everything runs at the edge. Zero origin servers.

## Deploy it yourself

**Prerequisites**: A Cloudflare account + a domain on Cloudflare

```bash
# Install Wrangler
npm install -g wrangler
wrangler login

# Create a KV namespace
wrangler kv namespace create CACHE

# Add the KV namespace ID to wrangler.jsonc

# Deploy the Worker
npx wrangler deploy

# Generate and deploy the frontend
python3 write_site.py
npx wrangler pages deploy public --project-name YOUR-PROJECT-NAME
```

## Key Concepts Demonstrated

- **Edge-first architecture**: every component runs in Cloudflare's network across 330+ data centers
- **AI at the edge**: LLM inference without managing GPU servers — Workers AI handles it natively
- **Stateful edge functions**: Workers KV enables memory persistence without a database
- **Zero-infrastructure deployment**: no EC2, no VPS, no Docker — just `wrangler deploy`
- **Full-stack in one platform**: DNS, CDN, compute, AI, storage, monitoring — all from one provider
